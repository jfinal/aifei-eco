## HIO 自主架构（Handler + Input + Output）

Aifei 采用 HIO 自主架构，让用户自主掌控处理流程、数据结构。

Handler 用于掌控处理流程，Input、Output 用于掌控输入输出数据结构。

HIO 的实现需要由开发者自主决定，可参考 aifei demo 实现自己的 HIO。

如需获取企业级 HIO 最佳实现，可订阅 VIP 会员。
