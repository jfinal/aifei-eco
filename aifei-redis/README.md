# aifei-demo

用于演示 `Aifei AI Coding 框架` 的 **Just Service 开发范式**。

## 主要文件

- AifeiDemo 为启动入口。
- AppConfig 为配置中心。
- TaskService 为 Just Service 开发范式演示。
- cn.aifei.demo.common.arch 包下的文件为 HIO 极简实现。
- cn.aifei.demo.common.db 包下面的文件由 Generator 生成，无需人工干预。

## 运行、打包、部署

见 "/必读/_运行-打包部署.txt" 文件内容。

## HIO 自主架构（Handler + Input + Output）

Aifei 采用 HIO 自主架构，让用户自主掌控处理流程、数据结构。

Handler 用于掌控处理流程，Input、Output 用于掌控输入输出数据结构。

HIO 的实现需要由开发者自主掌控，可参考 aifei demo 实现自己的 HIO。

如需获取企业级 HIO 最佳实现，可订阅 VIP 会员。
